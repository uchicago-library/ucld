UChicago Library Design System

Design tokens, components and guidelines for University of Chicago Library websites. Built on Bootstrap 5 with the Library's brand colours and typeface, and held to WCAG 2.1 Level AA.

Contribute to It

For people changing the system. Setup, architecture and conventions, alongside the repository.

Status and Adoption

In progress: this design system is a stabilization effort aimed for completion by November 2026. It is based on a planning document on Box.

Systems using it

  • LibGuides — Integrated. Uses Springshare stylesheet.
  • Day Pass — Integrated. Could benefit from a leaner output.css.
  • Main Website
  • Catalog
  • Book a Room
  • Digital Repository
  • Knowledge@UChicago - institutional repository.
  • Other library websites and services

Roadmap

  • Migrate the source SCSS code to the main library website repo.
  • Finalize the initial set of components and design tokens based on the most common patterns across the library's websites.
  • Test it by implementing it in the main Library website.
  • Add a utility to easily copy any <pre> or <code> content.
